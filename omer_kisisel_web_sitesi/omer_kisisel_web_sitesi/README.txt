ÖMER FARUK İNCE — KİŞİSEL WEB SAYFASI

Dosyalar:
- index.html: Sayfanın içeriği
- style.css: Tasarım ve renkler
- script.js: Footer'da yılı otomatik günceller

Bilgisayarda görüntüleme:
1. ZIP dosyasını bir klasöre çıkar.
2. index.html dosyasına çift tıkla.
3. Bootstrap CDN ve Google Fonts için internet bağlantısı gerekir.

Ücretsiz yayımlama:
1. GitHub hesabına giriş yap.
2. Yeni bir public repository oluştur (ör. omer-kisisel-site).
3. Bu klasördeki üç dosyayı repository ana dizinine yükle.
4. Repository > Settings > Pages bölümüne gir.
5. Build and deployment altında Deploy from a branch seç.
6. Branch olarak main, klasör olarak /(root) seçip Save'e bas.
7. Birkaç dakika sonra GitHub Pages adresin görünecektir.

DNS notu:
GitHub Pages'in varsayılan adresi DNS kayıtlarını elle yönetmeni gerektirmez. Ödev NS, MX, A ve CNAME kayıtlarını özellikle istiyorsa, ayrıca DNS yönetimi sunan ücretsiz bir alan adı/alt alan adı hizmeti seçmek ve kayıtları orada göstermek gerekir. DNS kayıtları alan adına ve sağlayıcıya göre değişir; rastgele değer girme. GitHub Pages özel alan adı için A/CNAME değerleri resmi belgelerde açıklanır:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

Önemli:
Bu paket web sitesi dosyalarını içerir; alan adı kaydı veya hosting hesabı otomatik olarak oluşturulmuş değildir.
